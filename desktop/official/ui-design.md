# 默认桌面 UI 设计

## 1. 定位

默认桌面是轻、浅、半透明的桌面：白色/浅色、圆角、毛玻璃。界面元素靠**材质分层**组织，而不是靠阴影、边框或额外的 elevation 堆层级。

三条硬约束：

1. 材质最多三层，不再深入。
2. 间距只属于第一层；第二、三层是内容层，不带 padding / gap。
3. 布局以静态尺寸为主；唯一的动态布局是 list 的滚动区。

应用内页面（设置、文件选择器）是独立的滞后部分，基本不使用毛玻璃，按实心表面 + 强调色处理。

## 2. 三层材质

| 层级 | 名称 | 材质 | backdrop blur | 间距 | 典型位置 |
| --- | --- | --- | --- | --- | --- |
| L1 | 背景 | 透明白毛玻璃 | 是，唯一使用 blur 的层 | 是，唯一有 padding / gap 的层 | 工具弹窗、通知、电源、音量、输入法外壳、搜索框 |
| L2 | 面板 | 半透明填充，叠在 L1 上不再 blur | 否 | 否 | `ui.barItem`、list 容器、候选词容器、密码框 |
| L3 | 强调 | 玻璃上为实心白；不透明表面上为强调色 | 否 | 否 | 当前项、选中项、主按钮 |

### 2.1 第一层：背景毛玻璃

- 唯一使用 `backdrop-filter` 的层。
- 负责 padding、gap、外层圆角。
- 内部只直接放第二层面板；文字、图标等内容放进第二/三层。
- 窗口标题栏、搜索输入框这类固定控件区属于 L1 自身的 chrome，不算内容层。
- 工具弹窗外壳、通知/电源/音量/输入法外壳、搜索框都属于这一层。

### 2.2 第二层：面板

- 叠在第一层上，只增加透明度，不再叠 `backdrop-filter`。
- 不放间距；内容与第三层贴合。
- `ui.barItem`、list 容器、候选词容器是这一层。
- 密码框是只有 L2 的特例，见 2.4。

### 2.3 第三层：实心强调

- 在玻璃上用实心白；在不透明表面上用强调色（蓝色）。
- 不放间距；条目自身保留 item 圆角。
- 当前项、选中项、主按钮使用这一层。
- L3 item 用 `iItem`，自带 `gRadius.item` 圆角。

### 2.4 层合并

需要单层时，不为了材质多包一层。把 L1 + L2 的等效透明度和 blur 算进同一个元素即可。

密码框是例子：只有 L2，直接合成一二层叠加后的透明度并加毛玻璃，避免为了材质多出一层 padding。

## 3. 间距与尺寸

- `sSize(n) = n × 12 + (n − 1) × 8`：n 个 12px 基元 + n−1 个 8px 间隙。用于第一层的整体跨度。
- `sSize2.padding = 8`，`sSize2.paddingx = 8`。
- 第二、三层不设置层间距；控件内部给内容留的 padding 不算层间距。
- 静态尺寸优先：窗口、面板、卡片、图标格用固定宽高，不根据内容撑开，不做响应式重排。
- 每个 L2 面板都要有明确的宽高；列表行高度固定，不靠内容撑开。
- 唯一的动态布局是 list 的滚动区；启动台和开始菜单的图标区按 list 处理。
- 放宽的例外：L2 允许显示/隐藏（搜索结果面板隐藏或固定 7 × 48）；过渡动画后续再加。
- list 目前按 `itemSize × n` 排，不支持 gap；后续让 list 支持 gap，才能和 `sSize` 的节奏完全对齐。

## 4. 圆角

- `gRadius.container = 18`：第一层容器、面板外壳。
- `gRadius.item = 10`：第二层面板、第三层 item。
- `gRadius.icon = 12`：应用图标容器。
- 窗口圆角由设置 `--window-radius` 控制，默认 18，范围 0–24。
- 其它地方不引入新的圆角值；需要更小的视觉圆角时，用 padding 内缩，让同一半径在同心位置成立。
- 第三层 item 用 `iItem` 创建，或使用同样的 `gRadius.item` 圆角。

## 5. 文字

| Token | 字号 / 字重 / 行高 | 用途 |
| --- | --- | --- |
| `gTextStyle.display` | 20px / strong / 1.3 | 页面、分区标题 |
| `gTextStyle.title` | 14px / strong / 1.4 | 面板标题、列表分组标题 |
| `gTextStyle.subtitle` | 13px / medium / 1.45 | 窗口标题 |
| `gTextStyle.body` | 13px / regular / 1.45 | 正文、列表项 |
| `gTextStyle.strong` | 13px / strong / 1.45 | 正文强调 |
| `gTextStyle.caption` | 12px / regular / 1.4 | 次要说明、元数据 |
| `gTextStyle.captionStrong` | 12px / strong / 1.4 | 小字强调 |
| `gTextStyle.micro` | 10px / regular / 1.2 | 标签、快捷键提示 |
| `gTextStyle.microStrong` | 10px / strong / 1.2 | 微小强调 |

- 字重统一走 `gTextStyle.weight`（`regular` / `medium` / `strong`）；换主题或深色模式时只需要改这里。
- 用字号、字重、颜色区分层级，不用 `opacity`；`opacity` 会连文字选区一起变淡。
- 颜色：`primary #111111`、`secondary #666666`、`muted #999999`、`inverse #ffffff`。
- 默认单行：`aLineText`，不换行、溢出省略、不可选。
- 需要文章式换行时才刻意使用 `txt` 等；常规界面不要让文本自然换行。
- 默认文本不可选择：桌面根节点 `userSelect: none`；需要复制的内容显式 `userSelect: text`（ID、密码、路径等）。
- 等宽文本用 `gTextStyle.monoFamily`；电量百分比、媒体播放时间用自绘等宽数字 `aNumberText`，避免比例字体跳动。
- 窗口标题用 `subtitle`；面板标题用 `title`。

## 6. 颜色与强调

- 基础是浅色中性面：玻璃 `rgba(245, 245, 245, 0.8)`，面板 `#ffffff88`，实心 `#ffffff`。
- 强调取决于基底：
  - 玻璃上：实心白。
  - 不透明表面上：蓝色 `#00aaff`（主按钮、开关、当前项）。
- 蓝色是预期强调色；后续可配置，连白色也可以换。当前不展开主题系统。
- 选中态只保留一种表达，不同时混用白底、白底 + 阴影、淡蓝底、黑色 6% 底。
- 文字颜色使用 token，不在业务代码里临时写 `rgba`。

## 7. 阴影

表面阴影只有两种：

| Token | 值 | 用途 |
| --- | --- | --- |
| `gShadowStyle.window` | `0 12px 40px #00000033` | 服务端绘制的窗口框架 |
| `gShadowStyle.panel` | `0 2px 12px #0000001f` | 工具弹窗、搜索框、开始菜单、确认框等小面板 |

- 面板阴影要小；不要用窗口级的大阴影抬面板。
- 窗口焦点可以在同一窗口阴影配方上调整强度，但仍属于窗口阴影。
- 控件自身的小投影（按钮、滑块）不算表面层级。
- 新增表面先归入这两类，不引入第三套 elevation。

## 8. 图标

图标只用两种来源：

1. 自绘图标生成器 `getIconXEl`。
2. 应用图标主题。

- 不使用 CSS 画图标，不使用 `✓ ○ ☐ v` 等文本字符当图标。
- 图标本体顶格绘制；留白在 `getIconXEl` 调用时用 `padding` 统一设置，不在图标数据里各画一圈内边距。
- 图标尺寸按所在位置固定，不靠内容撑开；工具栏用 20，菜单/标题栏用 16–18，应用图标容器用固定像素。
- 线宽、填充风格跟随生成器，不在业务代码里临时改。

## 9. 动效

- 出现：模糊 + 透明 → 清晰 + 不透明。
- 消失：模糊 + 透明 + 缩放。
- 移动：位移。
- 不打破层级关系：需要改变层级时，优先用位移/缩放「躲开」，不要直接换材质造成视觉突变。
- 动效统一由 `myde-ui` 的 `AnimationGear` 驱动；新动效优先用它，不要手写 `requestAnimationFrame` 轮询或叠加 CSS transition。时长、曲线、路径沿用 `ui.ts` 现有的 easeOut 和短时长。
  - 状态就是一组数字字段（如 `{ x, y, opacity }`），任意数值都能插值。
  - 支持命名状态和状态图；`moveTo` 可去命名状态，也可只传要变化的部分字段。
  - 动画可被打断，新目标会从当前视觉值继续，不会跳回起点。
  - `duration: 0` 可直接跳转；每次 `moveTo` 可临时覆盖时长和缓动曲线。
  - 通过 `setUpdateCallback` 把当前值写进 DOM；引擎本身不依赖 DOM，也能驱动 TUI。
  - 状态回到自身可实现循环动画；`timingFunction` 提供常用缓动曲线。
- 列表滚动是动态布局的例外；列表项的进出可以使用模糊、透明和位移动画。

## 10. 组件模式

- 禁止使用 select input（file color），因为它们的弹窗无法渲染，title也是同理。内建用dom画出来的软件如设置、文件选择器也禁止使用 select input file等，自己画。

### 10.1 工具弹窗

- L1：`ui.bar` 或默认工具外壳，毛玻璃，负责 padding / gap。
- L2：`ui.barItem` 面板。
- L3：条目、当前项、滑块。
- 通知列表用 `uScrollList`，没有通知时在列表区域内居中显示空提示。
- 剪贴板列表同样用 `uScrollList` 复用空提示；底部两个清空按钮各放一个 L2，横向 grid 等分。
- 电源模式用 `uSegmented` 横向等分；电池信息用 `uBatteryInfo`，电池设备行用 `uBatteryRow`，设备行的电池图标和百分比一起靠右。
- 系统菜单用 `uSystemMenu`：锁屏，以及关机 / 重启 / 挂起。
- 互联弹窗固定宽度；本机 ID 在行内单行省略，不参与撑宽弹窗。
- Wi-Fi / 蓝牙 / 互联的开关行带对应图标，整行点击即可切换，不必只点开关。
- 第一个 L2 承载状态氛围动效，画在内容下层：Wi-Fi / 蓝牙是水波，互联是环绕圆点，电源整行作为电池进度条；状态关闭或弹窗收起时不显示，动画也不运行。
- 参考实现：音量、通知、剪贴板、电源、输入法、系统菜单。

### 10.2 输入法

- L1：候选窗外壳。
- L2：候选词容器。
- L3：当前候选词实心白。
- 预编辑、辅助文本放在 L2，不直接放 L1。

### 10.3 密码框

- 只有 L2；加毛玻璃和 L1 + L2 的等效透明度，不额外包 L1。
- 占位文字用 `muted`。

### 10.4 搜索 / 启动器

- L1：毛玻璃外壳，负责 padding / gap，使用 `panel` 阴影。
- L2：输入面板、结果面板。
- L3：搜索结果行；选中项用实心白。来源标签用 `sourceTag`。
- 输入框放在 L2 输入面板内，不作为 L1 的直接内容。
- 结果面板可以显示/隐藏；显示时固定 7 × 48，超过后由滚动列表接管。这里允许 L2 的显示/隐藏，动画后续再加。
- 空提示由 `uScrollList` 在列表区域居中显示。

### 10.5 窗口

- 服务端绘制的标题栏属于窗口框架，使用 `window` 阴影。
- 标题栏 38px，标题 13px / 500，右侧控制按钮 22px 圆形。
- 窗口圆角跟随 `--window-radius`；最大化时直角、无外阴影。

### 10.6 设置 / 文件选择器

- 应用内页面，滞后设计；基本不使用毛玻璃。
- 使用实心表面 + 蓝色强调；表单控件、开关、分段控件暂时保持现有形态。
- 后续再按三层模型重新收敛。

### 10.7 启动台 / 开始菜单

- 图标区按 list 处理，可以滚动。
- 其它尺寸固定，不随内容重排。

### 10.8 媒体

- L1 外壳内放两个 L2：顶部播放器标签一个，下面内容一个。
- 标签 L2 高 `sSize(1)`，标签区是横向滚动列表，标签项宽 `sSize(2)`；标签文字在 L3 里垂直居中，选中的标签用实心白。
- 内容 L2 高 `sSize(5.5)`，封面 `sSize(2.5)`。
- 内容从上到下：封面、标题 / 艺术家、进度条、控制按钮。
- 控制按钮严格居中；当前时间和总时长绝对定位在按钮左右两侧。
- 没有播放器时隐藏标签 L2，在内容 L2 上居中显示「没有播放器」遮罩。

### 10.9 列表与空提示

- 列表统一用 `uScrollList`：它包装 `dynamicScrollList`，新增 `empty` 空提示参数。
- 空提示用单行 `aLineText`，在列表区域内水平 / 垂直居中；有内容时隐藏。
- 选择型列表统一用 `uChoiceRow`：L3 行，左侧图标 / 文本，右侧详情和标记。
- 选择标记只用于托盘菜单：`checkmark` 用勾，`radio` 用圆环 + 圆点；标记统一在右侧，左侧是托盘图标。
- 其他列表不显示选择标记，只用 L3 实心白强调当前 / 已连接行。
- 托盘菜单不铺白底，只显示勾 / 圆，左侧图标和右侧标记形成平衡。
- 列表项进出沿用 `dynamicScrollList` 的默认动画，不额外写一套过渡。
- key 必须稳定（搜索结果用来源 + id），否则列表会把所有行当成新项，只播放进出、没有位移动画。
- 列表项是 L3，使用 `gRadius.item` 圆角；列表本身不加层间距。

### 10.10 虚拟键盘

- L1：整块玻璃面板，负责 padding / gap；标题栏是 L2，键帽是 L3 实心白。
- 标题栏标签直接是极简键盘 / 常规键盘 / 触控板 / 表情 / Unicode；键盘标签只放键帽，常规配列、触控板键盘位置、粘滞键和输入法收在标题栏齿轮打开的“键盘设置”页里。
- 修饰键激活态用蓝色主色 + 白色文字；当前页标签和设置页里的当前选项用 L3 实心白。
- 候选栏是键帽上方一条 L2 玻璃条：合成文本、候选词、两端的翻页箭头；高度固定，没有合成时是空条，打字时键帽不移动。
- 触控板页顶部只有“不显示键盘 / 极简 / 常规”一个开关；下面是触控面板 + 左/中/右键 + 右侧一个可滚动的条形区域，选中键盘时和键盘分栏显示，手势沿用物理触摸板。
- 表情、Unicode、触控板页在上层内容面板内滚动，不额外加材质层。
- 锁定键盘只保留按键网格，没有标题栏、设置页和页面切换；锁屏密码行另有键盘开关按钮。

## 12. 新界面检查清单

- [ ] 材质不超过三层。
- [ ] L1 只直接放 L2 面板，没有直接放文字/图标。
- [ ] L2/L3 没有 padding / gap。
- [ ] L3 item 使用 `iItem` / `gRadius.item`。
- [ ] 圆角来自 `gRadius`，窗口用 `--window-radius`。
- [ ] 文本默认 `aLineText`，没有用 opacity 做层级。
- [ ] 默认不可选；需要复制的地方显式 `userSelect: text`。
- [ ] 阴影是 `window` 或 `panel`，没有第三种表面阴影。
- [ ] 图标来自生成器或应用图标主题。
- [ ] 尺寸静态；只有 list 滚动区是动态的。
- [ ] 动效没有打破层级关系。
