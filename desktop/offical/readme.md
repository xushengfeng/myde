# 默认桌面

## 触控

触屏按接触点映射成独立指针：一根手指对应一个 `pointerId`，各自产生 down/move/up，第一根手指 `isPrimary` 为 true。点按由输入聚合层合成 `click`，只在单指接触（没有出现两指以上）且主指针抬起时合成，多指手势留给交互层。

- DOM 模式（window）：浏览器为触摸生成的 pointer 事件和其他指针一样进入聚合层，`pointerId`/`isPrimary` 原样保留；`html`/`body` 设置 `touch-action: none`，关闭浏览器自己的平移、缩放与双击放大手势
- evdev 模式（desktop）：MT-B 用 `slot` + `ABS_MT_TRACKING_ID` 跟踪每根手指，绝对坐标按屏幕量程映射；没有 tracking id 的旧设备退回单指 `BTN_TOUCH` 路径
- 桌面光标和窗口转发只跟随主指针，其余指针事件照常派发给 UI，供交互层实现长按、双指缩放等手势
- 桌面与 UI 只监听 pointer 事件，不依赖 mouse 事件

### 触摸板

desktop（evdev）模式下触摸板事件由仓库的 `src/utils/touchpad.ts` 封装成 `move`/`scroll`/`button` 语义事件，桌面只订阅转换结果，window 模式由宿主系统处理。绝对坐标只用于计算位移与手指数，不映射成光标位置。

- 单指轻触左键、双指轻触右键、三指轻触中键；轻触要求接触不超过 180ms、位移不超过 1.3mm（按设备分辨率折算，分辨率缺失时按 libinput 的 69×50mm 触摸板估算）；判定期间不移动光标，确认是移动/拖拽后再补上攒下的位移
- 单指移动光标；接触中移动超过 1.3mm 就按移动处理，不点击；按住超过 180ms 没有移动也不点击（libinput 的 hold 行为）
- 轻触在抬手时才按下左键，并等 180ms 拖拽窗口：窗口内第二下按住（移动超过阈值或保持到超时）沿用按住的左键进入拖拽，抬手结束拖拽；窗口内第二下快速抬起则按双击处理（先抬起上一次点击，再按下本次）
- 拖拽抬手立即抬起左键；没有第二下时拖拽窗口结束自动抬起，完成一次点击
- 两指移动产生自然滚动（内容跟随手指）；三指及以上移动单独发 `multiStart`/`multiMove`/`multiEnd`，官方桌面用横向移动切换虚拟屏
- 同一轮接触里按过物理按键就不再合成轻触，物理按下会取代待判定的轻触或并入已按下的左键
- MT-B 设备用 `slot` + `ABS_MT_TRACKING_ID` 跟踪每根手指；没有 tracking id 的旧设备用 `BTN_TOOL_*` 手指数；完全没有接触信号的设备只保留光标移动

## 虚拟桌面

一个窗口占一个虚拟屏；空桌面始终存在，启动台固定在最右，空桌面在启动台左边。常规状态和全局预览共用同一个窗口层，每个虚拟屏通过自己的 `transform` 计算位置和缩放，用 `AnimationGear` 补间，不再整体缩放外层容器。

- 常规状态：当前屏在视口中央，左边是更旧的应用屏，右边是空桌面，空桌面右边是启动台
- 启动台：固定在最右，显示应用图标，点击图标启动应用；和空桌面一样不参与全局预览，新窗口仍然占用空桌面。进入/退出预览时启动台留在原位缩小、模糊并淡出，层级在应用虚拟屏下面
- 切换后默认 3 秒内保持原来的空间顺序（缓冲），期间往左多滑几个屏还能直接往右滑回去；到点后按最近使用顺序在内部重排，当前屏不动，重排不做动画
- 三指横向滑动跟手移动，一次可以跨过多个虚拟屏，松手按最近位置吸附；手指从左往右去左边的旧应用，从右往左去右边的空桌面；横滑倍率默认 4×
- 三指上下滑跟手改变全局预览进度：上滑逐渐展开 grid，下滑逐渐收回；松手按当前进度吸附到最近状态。不抬手时可以来回滑动连续进出，抬手后重新下滑也能退出
- `Super+←` / `Super+→` 沿当前顺序左右切换，`Super+Tab` 开关全局预览，`Esc` 或点击预览空白处退出
- 新窗口：当前在空桌面时直接占用它，并在右边补一个新的空桌面；当前在其他应用时，跳到最右的空桌面打开，视觉上从最右滑入
- 全局预览：只显示应用屏（忽略空桌面和启动台），最新的从右往左、再从上往下铺成 grid；行列数按屏幕宽高比估算，卡片保持虚拟屏比例；点击卡片切换过去，内容不接收指针，不显示关闭按钮

### 启动器

顶部启动器输入框有三个位置：屏幕外隐藏、常规模式上三分之一、全局预览顶部。默认隐藏，只接收文本，暂不执行功能。常规模式下三指下拉或 `Alt+Space` 从工作区外部顶部滑出，停在约上三分之一处；`Alt+Space` 或三指上滑可收起展开的搜索栏。展开/收起过程跟手，松手按进度吸附。

全局预览时启动器固定在 grid 上方并始终显示，不能用手势或 `Alt+Space` 收起；grid 顶部会为它留出空间。手势和按钮的行为是分开的：

- 三指上滑：搜索栏展开时收起；搜索栏隐藏时进入全局预览，并从外部滑到顶部
- 三指下滑：搜索栏隐藏时拉出；已展开时保持；全局预览里退出预览
- 常规已展开的搜索栏不能直接用手势进入全局；改用按钮 / `Super+Tab`
- 按钮 / `Super+Tab` 切换常规与全局：搜索栏可见时在 1/3 和顶部之间移动，隐藏时从外部进入顶部
- 退出预览时按进入前的搜索栏状态，回到常规 1/3 或隐藏；全局预览里三指上滑不改变搜索栏

## 窗口缩放

窗口没有边框，四周铺一圈透明热区：四条边各 6px，四个角 14px。按住热区拖动即可缩放，拖动上边/左边时窗口位置同步移动，最小尺寸 200×150（逻辑 px）。

- Wayland 客户端窗口在拖动中把新尺寸转成 surface 逻辑尺寸，每帧最多通过 `window.setSize` 下发一次，由客户端按自身约束重绘；客户端提交前的 `window.changed` 不覆盖桌面预览，抬手后短暂等待客户端几何，超时再以客户端实际尺寸为准
- 设置窗口这类桌面自己创建的 DOM 窗口只改 DOM 尺寸，不经过 Wayland
- 缩放中指针事件不转发给客户端；全局预览里隐藏热区，最大化窗口不能缩放
- 手动缩放后暂停该窗口的自动居中，与拖动窗口一致
- 悬停热区时光标变为对应方向的缩放形状（自定义光标已支持 `ew-resize` / `ns-resize` / 两个对角）

## 光标

自定义光标用「一个基座 body + 前后装饰层」组合，全部是 DOM，不使用 SVG。装饰层可以是横线、方框描边、圆角方块或白色加减线，过渡时旧层淡出、新层淡入。

已设计的形状：

- `default`：圆点
- `pointer`：圆角方形
- `text`：竖线；`vertical_text`：横线
- `context_menu`：较窄的中线为 body，上下各一条横线装饰
- `cell`：外框为 body（空心描边），横/竖两条装饰组成十字
- `crosshair`：横线 body + 竖线装饰组成十字
- `copy`：前面的圆角方形为 body，后面偏移的圆角方形为装饰
- `move`：菱形描边为 body，横/竖两条装饰组成十字
- `all_scroll` / `all_resize`：和 `move` 相同
- `grab`：16×16 无圆角方形；`grabbing`：10×10 小无圆角方形
- `no_drop` / `not_allowed`：小圆 body + 大斜线前景装饰
- `zoom_in` / `zoom_out`：外圆为 body，白色加/减为前景装饰
- `progress` / `wait`：静态米字装饰，body 是一个小圆点；`progress` 的圆点在左上，`wait` 的圆点在中间
- `help` / `dnd_ask`：三个水平圆点，中间圆点为 body，左右为装饰
- `alias`：左边圆点为 body，右边一个方形装饰

形状之间用 `AnimationGear` 补间 body 的几何参数（宽、高、圆角、旋转），所有形状对先共用同一套过渡（150ms easeOut），个别 pair 可以之后单独覆盖；装饰层独立淡入淡出。图片光标和隐藏在形状之间直接切换，不做补间。窗口缩放热区的 `localShape` 覆盖也走同一套过渡。

没单独设计的 resize 方向先复用现有横/竖/斜线几何：`e`/`w`/`col` 用横线，`n`/`s`/`row` 用竖线，`ne`/`sw` 用 `/`，`nw`/`se` 用 `\`。其余未提到的形状仍回落到默认圆点。

线 resize 之间保留内部方向语义：单向方向为 0/45/…/315，`ew`/`ns`/两个对角方向和 `col`/`row` 是双向线。过渡时按这个方向旋转：双向 ↔ 单向共线时不旋转，非共线才旋转；反向单向之间会转 180°。旋转只发生在过渡中，过渡结束立刻切回目标的无方向线条，静止帧本身不显示方向。

resize ↔ `move` / `all_scroll` / `all_resize` 过渡时优先用十字的一条臂作为 body：横/竖 resize 不旋转，直接作为对应的横/竖臂；斜 resize 统一用横臂作为 body 旋转成斜线（竖臂作为装饰），保证进入和退出用的是同一条臂、可逆。菱形外框和另一条臂作为装饰淡入/淡出。`move` 与其它非线 resize 形状的转换仍以菱形外框为 body。

`text` / `vertical_text` / `crosshair` 是一组独立的过渡：`vertical_text` 与 `crosshair` 共用横线 body，只淡入淡出竖装饰；`text` 与 `crosshair` 之间让竖线保持为 body，横线作为装饰淡入/淡出，不做旋转或尺寸伸缩。两条线的 body/装饰角色互换发生在过渡结束切回无方向帧时，视觉上连续。

每个设计可以带 `hotspot`，缺省为局部坐标原点（当前所有普通形状都在中心）。`progress` 的热点在左上小圆点 `(-8, -8)`，所以整个米字会偏移到指针右下；热点切换时视觉内容会随过渡一起平移。预览矩阵的 `normal` 行用红圈标出每个形状的热点。

`test/cursor/cursor_preview.ts` 把桌面自身的 `normal` 默认静态状态和全部形状按行、列铺成上三角矩阵（过渡来回播放，反方向共用同一格）。`normal` 行不参与动画；其余设计不同的单元格自动播放 `from ↔ to`，两端各停留约 1 秒，初相位错开避免整张矩阵同时闪烁。

## 退出

`Super+Shift+E` 或 `Ctrl+Alt+Delete` 关闭桌面窗口，结束当前桌面进程。

## 设置

顶栏不放设置入口，设置作为模拟应用出现在开始菜单里。设置窗口是桌面自己创建的 DOM 窗口，不是 Wayland 客户端，但和客户端窗口共用同一套窗口逻辑：

- 占用一个虚拟桌面（`viewData.addWindowScreen`），打开时居中，参与全局预览
- 点击后聚焦，点击桌面或其他窗口时失焦，键盘事件留在 DOM 内处理
- 标题栏可拖动，关闭时回收虚拟桌面和居中管理
- 打开中的设置窗口再次点开始菜单里的设置会跳回它所在的虚拟桌面

设置项：
- 外观：`icon.theme` 应用图标主题
- 显示：Wayland 客户端缩放 `desktop.scale`（100% / 125% / 150% / 175% / 200%）。缩放后 surface 逻辑坐标不变，
  客户端 buffer 与窗口 DOM 尺寸按比例放大；桌面面板暂不缩放。winit 后端和普通窗口模式跟随宿主桌面，固定 1x。
  下方帧时间图表按需启动，实时采样桌面界面的 `requestAnimationFrame` 帧间隔，并按当前输出刷新率画出预算线
- 滚动：触摸板双指滚动速度 `desktop.touchpadScrollGain`、自然滚动 `desktop.naturalScroll`
- 手势：三指横滑切屏倍率 `desktop.switchGestureGain`（默认 4×）、切屏后重排延迟 `desktop.reorderDelay`（默认 3000ms）
- 输入法：候选窗预编辑 `ime.panelPreedit`（`auto` / `always` / `never`）
- 互联：启用开关、本机 ID、已配对设备列表和忘记设备；添加设备时显示本机配对 ID/PIN，输入对方配对 ID/PIN 和是否记住
- 窗口：新窗口居中，保存到 `desktop.centerWindows` 命名空间
- 关于：重启桌面，重新载入桌面界面（会关闭正在运行的窗口）；不会重启 myde 进程

顶栏有互联工具，类似 WiFi：开关互联、显示本机 ID、列出已记忆和当前连接的设备；点击设备可在连接/断开之间切换。互联开关状态保存在 `connect.enabled`。

`test/frametime` 用同一份 `src/frame_chart.ts` 做独立预览：`pnpm test:frametime` 启动 vite 后，在 myde 里用浏览器打开终端输出的地址；可切换窗口与刷新率、实测刷新率，并用持续负载或一次性长帧验证图表。

## 输入法

通过 `MSysApi.inputMethod` 连接 fcitx5，桌面作为输入上下文客户端处理按键，不实现 Wayland 的 input-method 协议。

- 只拦截实现了 text-input 的聚焦窗口；没有 text-input 的客户端按键原样转发，输入法不生效
- 预编辑和上屏走 `input.text`，候选窗是桌面覆盖层，优先贴 text-input 光标矩形，缺失时贴鼠标
- 顶栏输入法工具显示 中/英/关，点击后在列表里直接切换输入法；`keyboard-us` 作为关闭输入法项，选中后按键直接转发给客户端
- 默认快捷键：`Ctrl+Space` 激活/停用合成，`Super+Space` / `Super+Shift+Space` 切换输入法
- 配置在 `settings.json` 的 `ime` 命名空间：`toggle`、`nextIM`、`prevIM`、`panelPreedit`
  - `panelPreedit`：`auto`（默认，fcitx 已在发内联预编辑时候选窗不重复显示）/ `always` / `never`
- 候选窗和托盘弹窗的视觉分别在 `src/ui.ts` 的 `imeCandidatePopup` / `imeTrayPanel`，静态预览见 `test/ui_example/ui_demo.ts`
